# Eco_essence

## Concept 

Ce projet est un comparateur en ligne des prix de l'essence en France comme il en existe des centaines,/
sa particularité est de proposer en même temps une **prédiction à J+1** des prix pour chaque station ainsi qu'une **tendance**.

## Environnement technologique

Toutes les données sont stockées sur un serveur **AWS S3** et le rendu est fait à partir de **streamlit**.
